# Bug Fix

1. Reproduce or inspect the failure.
2. Check `docs/ops/KNOWN_ISSUES.md` only if the symptom matches a known operational issue.
3. Identify the smallest root cause and patch only the owning surface.
4. Add or run focused regression checks.
5. Report root cause, fix, verification, and residual risk.
